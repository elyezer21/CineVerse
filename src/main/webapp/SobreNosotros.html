Sobre Nosotros

Somos tres estudiantes de Ingeniería de Software en la Universidad Tecnológica de Panamá. Este proyecto es el resultado de nuestro trabajo conjunto en la asignatura de Programación de Software II.

01
Elyezer Portillo
Backend Developer Y Líder de Proyecto
Carrera: Lic. Ingeniería de Software
Grupo: 1SF-141

Responsable del servidor, la base de datos y la integración de APIs externas que alimentan CineVerse. Trabajó con SQL, Java y HTML/CSS, y se encargó de que la lógica del backend funcionara de forma estable y segura durante todo el desarrollo.

02
Amir Acevedo
Frontend Developer
Carrera: Lic. Ingeniería de Software
Grupo: 1SF-141

Creador de las interfaces y las interacciones visuales de CineVerse. Con HTML, CSS y JavaScript construyó las páginas del catálogo, el reproductor y el sistema de favoritos, priorizando una experiencia fluida y atractiva.

03
Yamar Camarena
UI/UX Designer
Carrera: Lic. Ingeniería de Software
Grupo: 1SF-141

Encargado del diseño visual y de la validación funcional del sitio. Definió la paleta de colores, la tipografía y la estructura de cada página para que CineVerse tuviera una identidad coherente y profesional. También realizó las pruebas de navegación para garantizar que todo funcionara correctamente.
